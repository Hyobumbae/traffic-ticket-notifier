# Automated Traffic Ticket Notifier — Interactive Demo

Single-file interactive demo of the **OCR & Auto-Mail System** built with
Microsoft Power Automate + AI Builder (AI Hub), submitted to the LR AI Contest.

**Live demo:** open the GitHub Pages URL for this repository.

The page is fully self-contained (PDF engine and all sample documents are
embedded). Scanned-ticket OCR and the real e-mail send additionally use
CDN-loaded libraries (Tesseract.js, EmailJS) and therefore need an internet
connection.

All names, vehicles and addresses in the demo are fictitious.
